# 奶系模拟人生 3D（NaiFamily Sims 3D）

基于 **Three.js + WebGL** 开发的奶龙同人「奶系家族」3D 模拟人生网页游戏——**浏览器打开即玩，零插件安装！**

## ✨ 核心玩法特色

- **首发 3 位可控家庭成员 + 1 位常驻黏人邻居（可解锁同居）**
  - **奶蛙**：梨形肚肚、绿环蛙眼、深色手脚，自带「传染性捧腹狂笑」与名画艺术魂。
  - **奶鼠**：大圆粉耳、细长弯尾、零食重度依赖，拥有专属「奶鼠豪华零食柜」。
  - **奶豆**：超迷你圆球小短腿、“身体 98% 是大脑”的理性学霸与代码创收担当。
  - **奶粉（常驻黏人邻居 NPC → 可邀同居）**：粉白配色傲娇大个子，与奶鼠形影不离！会频繁上门找奶鼠**怀里贴贴抱抱、心形打卡合影**，也会手痒**跳起来压扁弹起奶鼠**，奶鼠还能掏出**红绳反遛奶粉**！刷满友谊 ≥ 65 或羁绊 ≥ 60 后即可**邀请奶粉搬来同居**，解锁第 4 位可控室友与樱花公主床！
- **正宗《模拟人生》3D 实时体验**
  - 360° 自由旋转/缩放/平移镜头，支持**全墙 / 半切墙 / 隐藏墙**视角切换（`H`）与日夜动态光影。
  - 头顶随心情变色的旋转**绿色晶锥（Plumbob）**、6 大需求条（饥饿/如厕/精力/社交/卫生/娱乐）、情绪 Moodlet 状态卡。
  - 点击家具或角色弹出**《模拟人生》经典互动菜单**、左侧垂直**行动队列**、A* 自动寻路与**自主意识 AI**。
- **深度社交 & 抽象随机事件**
  - 友善 / 搞笑 / 整蛊 / 专属羁绊四大互动分类，支持双轨**友谊值 + 相爱相杀羁绊值**。
  - 内置 8 套以上分支随机事件卡（《奶粉凌晨送奶茶》《奶蛙狂笑遭物业投诉》《奶鼠零食失踪悬案》《奶豆〈奶鼠宇宙论〉爆火》《肥嘟嘟&牛来误入前院》等）。
- **简化建造装修 & 打工赚钱 & 自动存档**
  - 一键切换 4 套全屋装修主题色，随时购买新家具并支持旋转落位摆放（`B` / `R`）。
  - 支持出门上班、画架创作《奶蛙名画》、电脑写代码赚取 `§` 奶币，并自动保存至浏览器本地。

## 🚀 本地运行

```bash
npm install
npm run dev
```

打开浏览器访问 `http://localhost:5173` 即可游玩。
